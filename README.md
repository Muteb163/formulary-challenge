# Formulary Challenge

A serious game for teaching pharmacoeconomic analysis to pharmacy students. Players advise a hospital Pharmacy and Therapeutics Committee across three rounds:

1. **Sort the requests**: choose CMA, CEA, CUA or CBA for each request.
2. **Run the numbers**: four full cases with calculations (total costs, ICER, QALYs, ICUR, net benefit, benefit-to-cost ratio) and a recommendation.
3. **Face the committee**: interpret results and spot flaws in analyses.

Play it at https://muteb163.github.io/formulary-challenge/

The game is a single HTML file with no server. At the end, each player gets a result code; instructors can read codes at the `#instructor` page.
